# Better Me · 我的状态养成计划

为 21 岁、166 cm、48 kg 男生准备的响应式习惯打卡网页。纯 HTML、CSS 和 JavaScript，不需要安装依赖，也不依赖外部图片或字体。

## 打开

电脑可以直接打开 `index.html`。推荐在此文件夹运行 `node server.js`，再打开 http://localhost:3000。

手机和电脑连接同一个 Wi-Fi，手机打开启动时显示的局域网地址（如 `http://192.168.1.10:3000`）。保持电脑与服务运行；网络需允许设备互访，系统防火墙需允许 Node 的局域网连接。不同访问地址、不同浏览器分别保存数据。

仓库包含 GitHub Pages 自动发布配置。仓库设置中将 Pages 的发布来源设为 GitHub Actions 后，每次推送到 `main` 分支都会发布网页。上线后使用固定的 HTTPS 网址，手机与电脑无需连接同一 Wi-Fi，也不需要让电脑开机。

发布仅包含 `index.html`、`styles.css`、`app.js`、`favicon.svg`，不会包含测试浏览器资料或本地备份。首次从本地网址转到线上网址时，请先在旧页面导出 JSON 备份，再在新页面导入。

## 功能

- 六项每日习惯：护肤、饮食、活动、体态、穿搭、休息；附具体做法。
- 当周日期切换、历史补记、完成度、连续全勤统计。
- 一周入门训练与恢复安排。
- 体重录入、按实际日期绘制趋势、历史编辑。
- 身高和年龄设置。
- 浏览器自动保存，多标签页更新；JSON 备份导入导出。
- 移动端底部导航、键盘操作、减少动态效果支持。

数据只保存在当前浏览器。手机和电脑之间通过导出、导入 JSON 转移记录，不会自动同步。导入前有明确的替换确认。浏览器隐私模式或清理数据可能影响保存，请定期备份。

体重初始记录采用用户提供的 48 kg，不生成虚构的历史、打卡或趋势。健康内容为温和的日常习惯与一般入门示例，不设体重期限、减脂任务或医疗承诺。
